Every use case of the API (`UC-…`) goes from the backlog to a merged pull request, one at a time,
as the [Development Workflow Document](../requirements/documents/development-workflow-document/)
describes. Which of them are done is tracked in the heimdall-api repository, not on this site, so
that the tracker changes in the same pull request as the code it describes.

See the [use case status](https://github.com/artur-rios/heimdall-api#use-case-status) section of the
heimdall-api README for the current list. The use cases themselves are specified in the
[Use Case Specification Document](../requirements/documents/use-case-specification-document/).
