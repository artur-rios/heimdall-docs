 23///         parameter and no body field names an identity, so there is no way to ask for somebody
 24///         else's data. The rule is enforced by the absence of the parameter rather than by a check.

 29///         copy than anyone, and Art. 15 is not conditional on the account being in good standing.
 30///         An anonymised record is a different matter — there is nothing left that relates to a
 31///         person — but it also cannot authenticate, so it never reaches here.
 32///     </para>
 33///     <para>
 34///         <b>What is deliberately absent.</b> Audit entries whose attribution has been cleared
 35///         under NFR-21 do not appear — those the subject made, or those made about them, and cannot: once cleared, not
 36///         person. Saying so on the document would itself be a re-identification, so the export
