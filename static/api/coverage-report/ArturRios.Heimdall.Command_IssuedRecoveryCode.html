 28///         they fall, and case is ignored. What remains is sixteen characters for a code issued
 29///         now, or eight for one issued before (two groups of four from <c>[A-Z0-9]</c>, stored as
 30///         the digest of the exact <c>XXXX-XXXX</c> uppercase form). Those keep matching until they
